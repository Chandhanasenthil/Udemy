Project Description – Udemy Clone Website

This project is a front-end clone of the popular online learning platform Udemy, built using HTML and CSS. The main objective of this project is to practice web design skills, layout structuring, and responsive design.

The website includes key sections such as:

A navigation bar with logo, search bar, and login/signup options
A menu bar for course categories
A featured/recommended courses section
Course cards with images, titles, ratings, and pricing
A clean and user-friendly layout similar to the original Udemy website

The design is created using CSS Flexbox and Grid to ensure proper alignment and responsiveness across different screen sizes.

This project helped in improving my understanding of:

HTML semantic structure
CSS styling and layout techniques
Responsive web design
UI design replication
🛠️ Technologies Used
HTML5
CSS3 (Flexbox & Grid)
